## Overview

This section contains the foundational documentation that every developer should understand before working with the Prismatic system. It covers the high-level architecture, technology choices, and design principles that guide the development process.

## Core Concepts

### Umbrella Application Architecture
The Prismatic application uses Phoenix's umbrella architecture to separate concerns and enable modular development. See [Architecture Overview](architecture-overview.md) for detailed information.

### Technology Stack
Our technology choices are driven by requirements for scalability, maintainability, and developer productivity. See [Tech Stack](tech-stack.md) for comprehensive details.
