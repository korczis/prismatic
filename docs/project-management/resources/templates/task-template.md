## 📝 Template Usage Instructions

### For New Issues:
1. Copy this template to the appropriate location
2. Rename file following convention: `[ISSUE-ID]-[brief-description].md`
3. Replace all placeholder text with actual information
4. Remove template sections that don't apply
5. Add to appropriate priority lists in task README.md

### For Updates:
1. Always update the "Updated" field in metadata
2. Add dated progress entries in chronological order
3. Update status when changing phases
4. Maintain cross-references to related issues
5. Update completion checklists as work progresses

### For Completion:
1. Ensure all acceptance criteria are met
2. Complete all testing and documentation requirements
3. Set status to "Completed"
4. Add final progress update with completion summary
5. Update related planning documents if needed
